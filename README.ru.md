# Расширение «Торренты» для Antresol

[English](README.md)

Находит и скачивает новые фильмы, сериалы, музыку и книги в медиатеку
[Antresol](https://antresol-app.github.io/antresol/ru/): поиск по торрент-сайтам, которые вы
подключили, выбор раздачи — и файл попадает в нужную папку. Только для взрослых профилей;
загрузками управляет администратор.

## Установка

1. В Antresol: **Настройки → Сервер → Расширения → Добавить расширение**, вставьте
   `https://github.com/antresol-app/antresol-addon-torrents`, **Проверить**, **Установить**.
2. Подключите хотя бы один источник (ниже).
3. Если источник за защитой Cloudflare (например, RuTracker), добавьте FlareSolverr (ниже).

Страницы расширения — в **Настройки → Сервер**, группа **Загрузки и источники**:
**Загрузки**, **Источники**, **Настройки загрузок** и **Слежение**.

## Источники

**Настройки → Сервер → Источники → Добавить источник.**

1. Выберите сайт: RuTracker, Rutor, Kinozal, NNM-Club и другие или книжный OPDS-каталог.
   Русские сайты — в начале списка.
2. Заполните, что просит сайт (логин и пароль или cookie). Открытым сайтам ничего не нужно.
3. Нажмите **Подключить**. Источник проверится, и по нему начнётся поиск.

Если источник с ошибкой — откройте **Источники**, ⋯ → **Изменить…** и исправьте данные.

Переезд с Prowlarr: **Источники → Импортировать из Prowlarr** переносит сайты и входы (папка
настроек Prowlarr должна быть подключена к Antresol как `/prowlarr`). С Sonarr, Radarr и
qBittorrent — **Настройки → Сервер → Переезд**.

## FlareSolverr — для сайтов за Cloudflare

Некоторые трекеры (например, RuTracker) закрыты проверкой Cloudflare на ботов. Расширение
проходит её через [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr) — вспомогательную
службу рядом с сервером. Добавьте её в тот же `compose.yml`, что и Antresol, под `services:`,
рядом с `antresol`, без `ports:`:

```yaml
services:
  antresol:
    # ... как было

  flaresolverr:
    image: ghcr.io/flaresolverr/flaresolverr:v3.5.2
    restart: unless-stopped
```

Выполните `docker compose up -d`. В течение полуминуты расширение найдёт службу по имени,
`http://flaresolverr:8191`: вводить ничего не нужно. В **Настройки → Сервер → Настройки
загрузок → FlareSolverr** появится «Найден рядом с сервером», и источники с ошибкой проверятся
заново. Пока служба не найдена, в этой строке показан тот же блок.

### FlareSolverr в другом месте

Если FlareSolverr уже работает у вас в сети или Antresol запущен не в Docker, укажите адрес в
поле **Адрес FlareSolverr** на той же странице и нажмите **Сохранить** (адрес сохранится, когда
ответит). Или задайте его в `.env` сервера: `ANTRESOL_TORRENTS_FLARESOLVERR_URL=http://<хост>:8191`.
Адрес из поля главнее переменной, переменная главнее найденной службы.

## Каждый день

- **Поиск → Найти и добавить** — найти то, чего ещё нет в медиатеке, и выбрать раздачу.
- Страница фильма или сериала — скачать фильм или сезон, или следить за сериалом, чтобы новые серии
  приходили сами.
- **Настройки загрузок** — в каком качестве искать, FlareSolverr.
